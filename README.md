Project ini berisi scene WebXR tugas pertama menggunakan A-Frame 1.7.1.

Tiga pertanyaan refleksi
1 Mengapa posisi objek yang terlihat pertama kali oleh pengguna memakai nilai z negatif?
jawab : Kamera default A‑Frame menghadap ke arah sumbu Z negatif. Jadi, jika objek ditempatkan pada z negatif, objek langsung terlihat di depan kamera saat scene dimulai.

2 Mengapa WebXR hanya aktif pada HTTPS atau localhost?
jawab : WebXR membutuhkan secure context agar interaksi dengan perangkat XR aman. HTTPS menjamin data terenkripsi, sedangkan localhost dianggap aman untuk pengembangan lokal.

3.Jelaskan perbedaan peran WebXR Device API, three.js, dan A-Frame dengan bahasa Anda sendiri  (cukup 2-3 kalimat saja per pertanyaan)
jawab : WebXR Device API adalah standar web untuk menghubungkan browser dengan perangkat XR. Three.js adalah pustaka grafik 3D yang menyediakan fitur dasar seperti kamera, material, dan renderer. A‑Frame adalah framework berbasis HTML yang mempermudah pembuatan scene 3D tanpa harus menulis kode WebGL/three.js secara langsung.
